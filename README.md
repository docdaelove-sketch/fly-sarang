# 🚀 날아라 사랑아! (Fly Sarang!) - 우주 젤리 디펜스

초등학교 저학년 아이들을 위한 **모바일 가로 모드 3D 우주 젤리 슈팅 게임**입니다.

## ✨ 주요 특징
1. **스마트폰 맞춤 조작**
   - **폰 기울이기(자이로 센서)**: 스마트폰을 양옆/위아래로 기울이면 1인칭 우주선이 부드럽게 비행합니다. (상단 `🧭 영점` 버튼으로 편한 자세에서 중심 맞추기 가능)
   - **왼손 엄지 조이스틱**: 화면 왼쪽 아래의 동그란 조이스틱을 움직여 조준점(크로스헤어)을 이동합니다.
   - **오른손 엄지 슈팅 & 슈퍼폭탄**: 오른쪽 아래의 큰 `🔥 발사!` 버튼을 누르고 있으면 연속 발사되며, `🌟 슈퍼폭탄` 버튼으로 화면 전체 젤리를 한 번에 터뜨릴 수 있습니다.
2. **5가지 우주 젤리 슬라임**
   - 🟢 **초록 말랑이**: 기본 젤리 몬스터
   - 🟡 **노란 통통이**: 좌우로 통통 튀며 다가오는 빠른 젤리
   - 🟣 **보라 분열이**: 맞추면 작은 미니 젤리 2마리로 쪼개지는 젤리
   - 🔵 **파란 실드맨**: 보호막을 두르고 있어 여러 번 맞춰야 하는 젤리
   - 🔴 **빨간 폭탄이**: 터질 때 **주변 슬라임들까지 도미노처럼 연쇄 폭발**시키는 폭탄 젤리!
3. **4가지 파워업 아이템 캡슐** (날아오는 보석 캡슐을 쏴서 획득!)
   - 🌈 **무지개 기관총** (초고속 컬러 레이저 연사)
   - ⚡ **자석 유도 레이저** (조준점 근처 젤리를 자동으로 추적)
   - 🌟 **슈퍼스타 폭탄 +1** (전체 올킬 폭탄 충전)
   - 💖 **하트 회복 & 무적 보호막** (체력 회복 + 일정 시간 무적)
4. **배경음악(BGM) 넣는 방법**
   - 직접 만드신 음악 파일 이름을 **`bgm.mp3`**로 바꾸어 이 폴더(`index.html`이 있는 곳)에 함께 넣어주시면 게임 시작 시 자동으로 재생됩니다!
   - 또는 게임 화면 오른쪽 위의 **`📂곡 변경`** 버튼을 눌러 스마트폰/PC에 있는 음악 파일을 즉시 선택해 틀 수도 있습니다.

## 🌐 GitHub Pages로 스마트폰에 링크 공유하는 방법
1. GitHub에서 새 저장소(Repository)를 만듭니다 (예: `fly-sarang`).
2. 이 폴더 안의 파일들(`index.html`, `style.css`, `game.js`, 그리고 직접 만드신 `bgm.mp3`)을 업로드합니다.
3. 저장소의 **Settings > Pages** 메뉴로 이동합니다.
4. **Branch**를 `main` (또는 `master`)으로 선택하고 **Save**를 누릅니다.
5. 1~2분 뒤 생성되는 `https://<아이디>.github.io/fly-sarang/` 링크를 스마트폰으로 보내면 바로 플레이할 수 있습니다! (※ iOS/Android 기울기 센서는 `https://` 주소에서 정상 작동하므로 GitHub Pages와 궁합이 아주 좋습니다.)
